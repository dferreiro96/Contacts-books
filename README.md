# Contact Book / Agenda de Contactos

A Python CLI program to manage a contact book: add contacts, list them, and save them in a dictionary.

Un programa de línea de comandos en Python para gestionar una agenda de contactos: añadir contactos, listarlos y guardarlos en un diccionario.

## Features / Funcionalidades

- Add contacts with name and phone number / Añadir contactos con nombre y número de teléfono
- Ask how many contacts to save / Preguntar cuántos contactos guardar
- Exit early by typing "fin" / Salir antes de tiempo escribiendo "fin"
- Store contacts in a dictionary (name → phone) / Guardar contactos en un diccionario (nombre → teléfono)
- Display the contact list numbered / Mostrar la lista de contactos numerada
- Input validation for the number of contacts / Validación de entrada para el número de contactos
- Option to create another contact book / Opción de crear otra agenda
- Clean and friendly messages / Mensajes claros y amigables

## Requirements / Requisitos

Python 3
